Golden Set — verificação humana do Telegram

Esta página ajuda a transcrever uma mensagem original, sem copiar preços do V4. Um segundo revisor deve repetir a transcrição sem consultar a primeira. Os resultados são comparados automaticamente só depois da submissão.

Ainda não existe um Golden Set certificado.

Sem duas observações humanas concordantes, fonte original verificável e aprovação independente, os resultados permanecem não certificados. Não introduzas chaves, sessões Telegram, conteúdo privado ou URLs assinados nos ficheiros públicos.

1. Escolhe uma mensagem real

Os códigos R1/R2 não provam por si só que duas pessoas diferentes verificaram a origem. Esse controlo é feito na aprovação manual.

2. Observa diretamente a fonte

Abre o evento correspondente no Telegram, compara a data e o jogo. Cola o texto integral copiado da mensagem apenas nesta página, ou escolhe uma captura feita por ti. A página calcula localmente SHA‑256. O conteúdo original não será incluído no JSON nem enviado para um servidor por este formulário.

3. Transcreve os preços Was / Now

Preenche manualmente todos os valores tal como aparecem na mensagem. As odds do V4 não são apresentadas para evitar viés.

4. Exporta a transcrição

O JSON abaixo inclui apenas os valores verificados, identificador, pseudónimo do revisor, momento de revisão e hash da fonte. Nunca contém o texto nem a imagem original.

Como entregar pelo Android

No GitHub abre o repositório nunovinhas-creator/asianodds-h1-lab, navega até data/lab/golden/reviews/, cria um novo ficheiro com o nome indicado, cola o JSON e propõe a alteração por PR. Se preferires, cola o JSON nesta conversa para eu criar a PR. Nunca partilhes o texto original, a captura com dados privados ou credenciais.
