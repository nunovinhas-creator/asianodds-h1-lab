## Safe functional change after P0 review

The retained functional change is **a single bounded queue-priority turn for old API-Football strict IDs already eligible under the existing #153 full-day identity checks and #155 free-plan ID policy**. It reserves at most ONE of 30 normal game checks; previously approved/quarantined work retains higher priority. All day/fixture evidence, time gates, daily API allowances and cooldowns remain unchanged. No additional provider request is introduced.

The GOAL FC Noah–Syunik historical locator demonstrates an audit opportunity, **not a verified binding of the GOAL competition to the originally observed competition**. An ID, identical team names, kickoff and a GOAL league label repeated in current GOAL data are insufficient to establish that external association. The new GOAL shortcut is therefore **removed from the productive integration**: no GOAL historical locator can enter this queue reservation and `recovery_turn` explicitly rejects any supplied GOAL target. `plan_exact_goal_ids` remains for offline cohort diagnostics only. The already existing explicitly reviewed GOAL process, including its official score hold, remains untouched.

The API-Football strict-ID pathway is not changed: existing `plan_index_ids`, `IndexProbe`, current response identity and regulation FT verification remain responsible for certification. This PR changes priority, not proof. GOAL recovery may only be reconsidered in a separately authorized PR with independently proven original competition identity and adversarial tests.
